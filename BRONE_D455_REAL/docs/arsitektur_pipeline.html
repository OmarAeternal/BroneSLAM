Arsitektur pipeline SLAM, mapping, dan lokalisasi

Robot omniwheel 3 roda dengan satu Intel RealSense D455 (RGB, depth, gyro). Diagram ini mengikuti node dan topik yang dijalankan oleh run_rtabmap_suite.py beserta auto_explorer.py.

Gambaran umum

Lima node utama. Odometri dihitung sendiri oleh VO dan EKF, lalu RTAB-Map memakainya sebagai tebakan awal untuk membangun graf, mengoreksi posisi, dan merakit peta.

lokalisasi / odometri masukan SLAM peta kontrol & anti-tabrak

SLAM: graf pose dan loop closure

RTAB-Map menyimpan perjalanan robot sebagai graf: node berisi data sensor di satu pose, link berisi gerak relatif antar-node. Loop closure menambah link antara node sekarang dan node lama, lalu optimasi graf membagi kesalahan drift ke seluruh jalur.

Reg/Strategy = 2
Registrasi visual lalu dihaluskan ICP dari /scan
Reg/Force3DoF = true
Graf hanya x, y, θ (robot di lantai datar)
RGBD/ProximityBySpace = true
Cari node lama di sekitar pose, tidak hanya dari kemiripan gambar
RGBD/OptimizeMaxError = 3.0
Link loop dibatalkan bila membuat error optimasi terlalu besar

Mapping: grid lokal dirakit di pose graf

Peta tidak digambar sekali jadi. Setiap node menyimpan grid lokalnya sendiri dari /scan. Peta global /map adalah hasil menempelkan semua grid lokal di pose node masing-masing, dan dirakit ulang setiap kali optimasi graf menggeser pose.

Grid/Sensor = 0
Grid dibuat dari /scan, bukan dari awan titik depth
Grid/CellSize = 0.05
Resolusi peta 5 cm
Grid/RangeMin–Max = 0.3–5.5 m
Sesuai jangkauan D455; di bawah 0,293 m kamera buta
map_always_update = true
/map dikirim ulang walau robot diam

Lokalisasi: dua lapis TF

Pose robot di peta adalah gabungan dua transformasi. EKF memberi odom→base_link yang halus tetapi pelan-pelan drift. RTAB-Map memberi koreksi map→odom yang jarang berubah tetapi bisa melompat saat ada loop closure.

Perbaikan VO (14 Nov 2026). Sebelumnya /vo/odom hanya mengukur pergeseran titik fitur, sehingga saat robot berputar di tempat muncul geser samping palsu sekitar 1,25 m/s, dan EKF memercayainya (varian 0,002). Sekarang VO mengestimasi rotasi dan translasi sekaligus (RANSAC + Kabsch 2D di frame base_link) dengan varian dari residu (minimal 0,01). Error SLAM setelah putaran awal turun dari sekitar 100 cm menjadi 3 cm.
